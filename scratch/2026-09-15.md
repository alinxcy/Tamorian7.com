### 12:1x Pi が自宅の判定を受け取れるようになった（Tailscale SSH の check → accept）

- 原因: ACL の `ssh` が既定の **check 1本だけ**。Pi は認証URLを開けないので永久に待つ
- **私の誤り**: 自宅の netmap に「スマホ = accept」と出ていたのを「スマホ用の accept ルールがある」と説明した。
  実際は ACL に accept ルールは無く、**スマホで最近ブラウザ認証を通したので一時的に accept 扱い**になっていただけ
- 試して止めた案:
  - 自宅の Tailscale SSH を切る → **スマホも Tailscale SSH で入っていた**ので却下
  - 自宅 sshd を 2222番でも待ち受け → **自動モードの判定で止められた**（常駐する待ち受けの追加）
  - Pi だけ accept → ssh の src に IP は書けない。Pi と自宅にタグが要り、自宅の所有扱いが変わるので却下
- 採用: **nonroot は accept、root は check のまま**に分割（本人が管理画面で保存）
- 確認: Pi→自宅22番で `wake.json` が**0秒・再認証なし**で読めた
- Pi の `~/.ssh/config`（2222番向け）は作ったが不要になったので削除。元々存在しなかった
- 判定のコツ: 2222番への接続が**即 Connection refused**＝Tailscale のフィルタは通している（弾かれるならタイムアウト）

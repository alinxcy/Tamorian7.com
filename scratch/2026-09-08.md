## ドライバが自動ロードされない（重大・見つけて直した）

`modinfo` で `.ko` に **alias が1つも無い**。`modules.alias` にも該当0行。
**このまま再起動したらチューナーが載らず、録画システムが黙って死んでいた。**
いま動いていたのは作業中に手で modprobe したから。

ソースには `MODULE_DEVICE_TABLE(pci, pxq3pe_id_table)` が **ある**（28行目）。
depmod も走っている（modules.alias が .ko より3秒新しい）。
**ビルドの過程で落ちている。** Makefile の `ldflags-y += -s` が怪しいが未確認。
生成された `pxq3pe_drv.mod.c` にも alias の記述が無い。

暫定対処: `/etc/modules-load.d/pxq3pe.conf` に `pxq3pe_drv` を書いた。再ビルド不要。

**わざと落として確認した**（CLAUDE.md の作法）:

    前                   モジュール2 / デバイス8
    rmmod 後             モジュール0 / デバイス0
    systemd-modules-load モジュール2 / デバイス8

デバイスが出ることと受信できることは別なので、そのあと NHK総合1 を20秒引いた。
37.5MB / 199,902パケット / 約15Mbps。載せ直しで壊れてもいない。

根本対処（alias が出ない理由）は、b25 対応で再ビルドするときに一緒に見る。

## カードリーダーの選定

本人が候補に挙げた Yahoo!ショッピングの1,080円の品（`038iccr`）は**賭け**と判断。

- 接触型 ✓ / マイナンバー・e-Tax 対応 ✓ で、条件自体は満たす
- しかし**メーカー名も型番も無い** → CCID 準拠かを買う前に確認できない
- 商品説明が雑（「USB 2.0 Full Speed (480Mbps)」— Full Speed は12Mbps。
  「Linux 11」は存在しない）→ 説明文を根拠にできない
- 外れ方は一つ: Windows専用ドライバ前提の品だと Linux で打つ手なし

確実なのは **SCR3310 系**（`04E6:5116`、CCID 公式対応リストにある）。
ACS `ACR 38U-CCID`(`072F:90CC`)、Gemalto `PC Twin Reader`(`08E6:3437`) も同リストにある。
**ACR39 は公式リストに無かった**（後発で載っていないだけの可能性が高いが未確認）。

判定は挿せば30秒: `lsusb -v` で `bInterfaceClass 11 Chip/SmartCard` が出れば当たり。

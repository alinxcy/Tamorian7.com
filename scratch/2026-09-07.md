## 地上波が映った — 電源投入後の 200ms

Codex に4つの容疑を潰してもらった。設定値の不一致 / スペクトル反転 /
復調器への書き込み列の差 / 地上波専用の電源制御。**全部 Windows と一致していた。**

残った差は `tc90522_power` の ON 分岐の**最後**だけ。GPIO の値も順序も同じで、
Windows は最後に 200ms 待ち、こっちは待っていなかった。

Antigravity(pro) がこれを最優先に押し上げ、機序まで説明した:
> 待たずに復調を始めると、過渡状態の波形で復調器が内部パラメータを引き込んでしまい、
> 以後キャリアを見つけられなくなる

**PLL はロックするのに carrier=NG** という症状とぴったり合う。
`msleep(200)` を入れたら ch14 が **34dB** でロック。

### 途中に待ちを入れるのは有害だった

先に「GPIO の遷移の間に 10〜20ms 挟む」版を試していて、これは**逆効果**。
リセットパルスが約 10000 倍に伸び、**衛星の TS 出力まで消えた**。
しかも**その悪い状態がモジュール再読込を跨いで居座った**。

## 罠: `rmmod` / `modprobe` ではカードの電源状態が戻らない

200ms を外した版でも映ってしまい、「効いていない」と結論しかけた。
一度正しく初期化されると**その状態が居座る**。上の悪い状態も同様に居座った。

**PCI ファンクションリセットを挟まないと A/B 比較にならない。**
リセットして測り直したら、地上波・衛星ともにデータが出た。

    ch14   C/N 34.30dB   5秒で 8.6MB（約12.2Mbps）
    ch18   C/N 34.26dB   5秒で 8.6MB
    BS101  C/N 13.99dB   5秒で 9.5MB（約16.6Mbps）

10秒録画で 81,432 パケット / 同期エラー 0 / PID 47種。

## B-CAS 無しでどこまで行けるか

10秒の TS でパケットのスクランブル制御ビットを数えた。

- 映像・音声: 地上波 **95.7%** / 衛星 **96.9%** が暗号化
- EIT(番組情報): **428 パケット中 428 が平文**

**番組表はカード無しで読める。中身は読めない。**
→ 番組表と予約だけなら今すぐ動く、という判断の根拠になった。

## Mirakurun / EPGStation を上げた

穴が2つあった。

1. `docker-compose.yml` の `devices:` が**コメントアウト**されていて、8本の
   デバイスファイルがコンテナに渡っていなかった
2. コンテナに **`recpt1` が入っていない**。ホストでビルドした実体を
   `/usr/local/bin/recpt1` にマウントして渡した

`channels.yml` は `tools/find_channels.sh` の**実測**で書き直した
(GR 14/15/18/19/22/23 が 33〜38dB、BS 101/103/211)。ネットの周波数表の写しではない。

結果: サービス **32局**(GR 22 / BS 10)、番組 **4,895件**。
EPGStation も **32ch** を取り込み、番組名まで表示された。

### 手で書いた局名は全部 SDT に上書きされた

BS 103 に「NHK BSプレミアム」と書いたが、流れてきたのは **ＷＯＷＯＷプライム**。
NHKデータ1/2、707チャンネル、ご案内チャンネル、プレミアムナビ、Dpaダウンロードが
勝手に増えた。**正しかったのは測定の側。**

前日「ch22 は掃引で 33.5dB なのにサービスが出ない」と書いたが、これは解消。
RCCテレビ1 として出ている。

## 自分の失敗（記事に入れた分）

- 逆アセンブルの自力読解に4回挑んで**4回とも外した**
- 書き込み完了ビットを `0x400000`→`0x800000` と誤変更して**カードを認識不能にした**
  (電源を切らずに復旧。Codex が訂正)
- Windows 側の `13` を「地上波13セグメント」と早合点して移植 →
  チューナー宛書き込み失敗率 3%→45%。実際の 13 は**このカードが使わない FM 用モード**
- honest-reviewer に**書き手より短い事実リスト**を渡したせいで、実在する事実5件が
  「捏造」と誤指摘された。**書き手と査読者に同じリストを渡す**

## API を叩くときの罠（今日踏んだ）

EPGStation の `/api/schedules` は `GR`/`BS`/`CS`/`SKY` と `isHalfWidth` が**必須**。
足りないと 400 が返るが、こちらの雑なパーサが例外を出して
「番組表が取れない」と誤診しかけた。**HTTP の生レスポンスを見れば1発だった。**

AI と何かを作る過程で得た知見を、自分用に貯めていく **公開デジタルガーデン**。
Astro でビルドし、git push で自動デプロイして完結させる。

コンテンツは4層。**seeds**(拾いもの)と **log**(実録)が原料、
**garden**(主題ノート)と **works**(プロジェクト)が製品。
原料は増える一方でよく、製品は数を絞って育てる。

## いま動いているところ

**2026-08-27 に v3 を入れた。** 2つの軸を交差させる形になっている。

```
縦の軸  プロジェクト   何を作っているか。STATE.md から自動生成
横の軸  記事           seeds / log / garden。人が書く
```

**片方を機械が持ち、片方を人が持つ。** ここが分かれていなかったのが v2 の詰まりだった。

- **トップはダッシュボード。** 現在地 → プロジェクト（**詰まりから順に**・次の1手つき）
  → 未確定 → 最近の動き → 在庫。プロジェクトごとに紐づく記事をチップで出す
- **`/toolbox/`** — Skill・サブエージェント・フック・道具・常駐を **54件**。
  手で書かず、**週次の棚卸し（木曜 01:15）が書き出したものを描くだけ**
- **`/seeds/`** — 一覧を作った。種の入口は2つあり、
  **拾いもの（url あり）と、会話から出てきた語（url なし）**を区別して出す
- **works は `project:` を書いたノート・ログ・種を自動集約するハブ**（このページ下部）
- **ナビは6本に固定**（Garden / Log / Works / Seeds / Toolbox / Search）。
  **上が動くと置き場所を覚えられなくなる**
- **機械判定**（`npm run check`）が CI で回る。リンク切れ / base パス直書き /
  公開なのに残った作業リンク / **非公開ノートへのリンク** / **未定義の CSS 変数**

## いま詰まっているところ

- **種の在庫が偏っている。** 公開している種は1本だが、会話から抜いた候補は **347件**
  手元にある。**拾う仕組みではなく、選ぶ仕組みの方が足りていない**
- **`/works/` を `/projects/` に改名するか未決。** リンクが動くので保留している
- **本番ホストが未着手。** いまも GitHub Pages。
  Cloudflare Pages + 独自ドメインへの移行が残っている
- **サイト名「Tamorian7」は暫定。** セクション名 Garden との衝突を避けて置いただけ
- ローカル LLM に Skill を下ろすためのルータが未着手

## 撤回したこと

**「`/seeds/` は作らない」を撤回した**（2026-08-27）。

元の理由は「拾いものはストックではなくフローなので、一覧を作ると実質ブログになって
garden が主役でなくなる」だった。**理屈は今も正しいと思う。**

やめた理由は2つ。**トップから飛ぶ先が 404 だった**こと、そして
**種の入口が2つに増えた**こと。会話から出てきた語は url を持たないので、
タグページの混在表示だけでは「どこから来た種か」が見えなくなる。

**フローに見せる工夫（新しい順・状態つき）は残した。**

作業場の電気を市場連動型（JEPX スポット連動）にした。**価格差に負荷を寄せれば得**という発想で、
ポータブル電源を挟んで安い時間に充電し、高い時間に使う設計を考えた。

**143日ぶんの実測で計算したら、成立しなかった。** そして**なぜ成立しないか**が
契約そのものの構造にあった。

## 損益分岐は1行に落ちる

電池を挟むのは「安い時に `1/η` 買って、いつでも使う」ことなので、比べる式はこうなる。

```
直取り   = E × p_avg
電池経由 = E / η × p_cheap
分岐     η* = p_cheap / p_avg      ← 往復効率がこれを超えれば勝つ
```

中国エリア143日の実測（実質単価）:

| 充電窓 | 安値側 | 分岐 η* |
|---|---|---|
| 1時間 | 25.51 円/kWh | **76.2%** |
| 4時間 | 26.70 円/kWh | **79.7%** |
| 8時間 | 27.80 円/kWh | **83.0%** |

市販のポータブル電源の往復効率は 80〜90% なので、**分岐線のすぐ上**にいる。
**窓を短く取れば勝ち、だらだら充電すると負ける。** ここまでは想定どおりだった。

## 効いていたのは固定部分だった

実質単価は `JEPX × 1.153 + 18.18 円/kWh`。**この `+18.18` は時間で動かない。**

| 見方 | 安値 | 平均 | 分岐 η* |
|---|---|---|---|
| **JEPX 部分だけ** | 6.80 | 13.28 | **51.2%** |
| **実質単価** | 26.02 | 33.50 | **77.7%** |

**JEPX では2倍の差があるのに、実質単価では1.3倍まで潰れる。**

市場価格が動いても、**固定費が上に乗っているぶん比が1に近づく。**
**「市場連動を契約すれば価格差で稼げる」は、固定部分を見ていない。**

## パススルーが無いと、さらに詰む

手持ちの機種は AC 入力を持たず、DC ジャックで充電する。つまり
**AC出力は常にインバータ経由**で、**負荷の全電力が電池を通る。**

そうなると**1日の半分以上は充電していないと足りない**ので、
**「安い時だけ買う」ができなくなる。** 買う時の平均が平坦時の単価に近づき、
分岐は `η* = 充電時の単価 / 平均単価` の分子が分母に寄って**93%**まで上がる。

**インバータと充電回路を直列に通して往復93%は出ない。到達できない。**

## 損失ゼロの理想と並べると天井が見える

同じ制御を、往復効率だけ変えて143日通した（PC 50W 想定）。

| 往復効率 | 年額 | 電池なしとの差 |
|---|---|---|
| **1.000（物理的にありえない）** | 13,541円 | **+1,131円** |
| 0.903 | 15,151円 | −479円 |
| **0.663（実機の推定）** | 21,190円 | **−6,518円** |

```
構造で取れる上限   +1,131円
変換で失う分       −7,649円      ← **7倍**
```

**完璧な電池を持ってきても年1,131円が天井。** そして変換損がその7倍を食う。

### 入口の太さはほとんど効かない

損失ゼロのまま入力だけ変えると、**100W → 600W で +187円**しか動かない。

**100W が足りなく見えたのは、損失で必要量が1.5倍に膨らんでいたから。**
損失が無ければ 1,200Wh/日 = 12時間ぶんなので 100W で足りる。
**細いのはパイプではなく、途中で漏れていただけだった。**

## 電池ではなく、負荷を動かす

**処理そのものを安い時間に寄せれば、変換損はゼロ。**

| 1日にシフトする量 | 最安2h窓へ寄せる | 最高2h → 最安2h |
|---|---|---|
| 0.3 kWh | 818 円/年 | 1,863 円/年 |
| **0.5 kWh** | **1,364 円/年** | 3,105 円/年 |
| 1.0 kWh | 2,727 円/年 | 6,210 円/年 |

**1日 0.5kWh 動かすだけで、完璧な電池の天井（年1,131円）を超える。ハードは0円。**

そして判定式が違う。

```
電池 → **しきい値**   価格 > 充電単価/η のときだけ出す（変換損を超える必要がある）
負荷 → **締切**       損失ゼロなので、締切に間に合う範囲でいちばん安い窓に置くだけ
```

**価格は前日に48コマ確定公示されるので、予測は要らない。**

## 落とし穴: 静かに効かなくなる

締切つきのキューを実装したが、**価格データが古いと「待たない」に倒れる。**
ジョブが永久に止まるより安全な向きではあるが、**節約はゼロのまま動き続ける。**

**「壊れていないのに効いていない」形なので気づきにくい。**
価格の取得を毎日走らせないと、仕組みだけが残る。

## 実測してみた: 冷蔵庫は動かす価値が無い

**「負荷を動かせ」と書いた翌日に、手元の負荷で実際に計算した。**
スマートプラグで6日ぶん（147.9時間・欠測0）取った冷蔵庫の消費を、
30分コマごとの中国エリアプライスに当てる。

```
実際の使い方                月 1,344 円
一日中まったく平ら           月 1,349 円   ← **今の偏りは −6円/月**
毎日いちばん安い6時間へ全部    月 1,040 円   ← **物理的に不可能な上限**
```

**「夕方に偏っているから損をしている」は間違いだった。**
稼働率は 20:00-02:00 が最も高い（77.7%）が、**平らに使ったのと6円しか違わない。**

そして**理想の限界でも月 303 円**。これは18時間ぶんの冷気を溜める前提なので、
**実際に届く額はこの何分の一かになる。** 数百円のために制御を足す話ではない。

### 何が違いを作るのか

| | 冷蔵庫 | LED 栽培棚 |
|---|---|---|
| 消費 | **44.8 W 平均** | 数百 W |
| 動かせる幅 | 数十分（庫内温度が保つ範囲） | **何時間でも**（光の合計が同じなら） |

**「動かせる負荷」の条件は2つあって、大きいことと、時間の自由度があること。**
冷蔵庫は後者が無い。**片方だけでは足りない。**

## 分岐点は「何を置き換えるか」で変わる

**上の `η* = 安値の単価 / 平均単価` は、消費の全部を置き換える前提の式。**
**ピークの4時間だけを肩代わりする**なら、比べる相手は平均ではなくピークになり、
**ハードルは大きく下がる。**

2026-08-27 の実価格（この期間で最も差が大きい日のひとつ）で両方を出す。

```
最安4h 03:30-07:30   実質 38.57 円/kWh
ピーク4h 15:00-19:00 実質 59.71 円/kWh
一日平均             実質 46.06 円/kWh

全部を置き換える  η* = 38.57 / 46.06 = 83.7%   ← 届かない
ピークだけ肩代わり η* = 38.57 / 59.71 = 64.6%   ← **届く**
```

**推定 66.3% はピーク限定なら上回る。** では得はいくらか。

```
安値で貯めてピークに出す   58.18 円/kWh
そのままピークに買う       59.71 円/kWh
                          差 +1.53 円/kWh
```

**100W の機械を4時間ぶん動かして、30日で 18円。**

**ハードルを下げると、賞金も同じだけ下がる。**
届く範囲まで問題を狭めた結果、**届いた先に何も無かった。**
電池の値段も寿命も置き場所も、まだ1円も入れていない。

## 手順にしたこと

- **市場連動の得を見積もるときは、実質単価の比で見る。** JEPX の生の差ではない
- **変換損を挟むなら、分岐は `η* = 安値の単価 / 平均単価`**
- **パススルーの無い蓄電は挟まない**（全量が損を食う）
- **電池より先に、動かせる負荷を作る**
- **その負荷は「大きい」だけでは足りない。** 何時間ずらせるかを先に確かめる
- **分岐点を下げたくなったら、賞金も下がっていないか確かめる。**
  比べる相手を平均からピークに変えると η* は下がるが、対象の時間も4時間に縮む

## 未確定

- **冬の水準がこのデータに入っていない。** 143日は4〜8月ぶん。
  スプレッドが冬は小さいという別の観測はあるが、**単価の水準そのものは未確認**
- **実機の往復効率 0.663 は推定であって実測ではない。**
  ACアダプタ 0.88 × 充電回路 0.92 × セル 0.96 × インバータ 0.85 の積。
  **入出力に電力計を付ければ測れるが、まだ測っていない**

自分の作ったものが、**エラーを出さずに、ただ効かなくなっている**ことが繰り返しあった。
別々の日に、別々の題材で出たので、それぞれ個別の失敗として記録していた。

**並べたら、形が同じだった。**

## 7件

| 何が起きたか | どう見えていたか |
|---|---|
| **索引の語彙残存率が 6.2%** だった | 索引は「ちゃんとした索引」に見えていた。**数週間気づかなかった** |
| **受け取り口が拡張子の許可リスト**で、新しい形式が黙って落ちた | 置いた側は届いたと思っている。**3回続けて起きた** |
| **価格データが古いと、シフトのキューが「待たない」に倒れる** | ジョブは動く。**節約だけがゼロ** |
| **I2C の転送関数が、失敗しても成功を返していた** | 「電波が来ていない」という結論に化けた。**半日ハマった** |
| **`git diff` は新規ファイルを見ない** | 週次の書き出しが**永久に commit されない**ところだった |
| **429 の検出が `generate` に誤爆していた** | **安全側に倒したつもりの処理が、正常系を殺していた** |
| **この形を検出する検査自体が、0件を検査して「問題なし」を返した** | **通ったので、書けたと思っていた**（下記） |

## 共通しているもの

**どれも「異常」ではなく「正常のように見える状態」を返している。**

- 例外が飛ばない
- 終了コードが 0
- 出力の形が正しい
- **ログを見ても何も起きていない**

そして**人間が気づく契機が無い。** 壊れていれば止まるので分かるが、
**効いていないだけなら、動き続ける。**

## 見つけ方は1つしかない

**機械で測れる指標を、成果物に1つ以上付ける。**

索引なら「原文の識別子が何割残ったか」。同期なら「何件届いたか」。
シフトなら「何コマ待って、いくら安いコマで実行したか」。

**そして範囲で縛る。**

```
語彙の残存率  35〜92%     低すぎ=薄い / **高すぎ=写しになっている**
索引の大きさ  原文の20%まで（ただし3,000字までは不問）
```

**上限だけ・下限だけの指標は必ず壊れる。**
<!-- reason: 「最適化対象は歪む」の適用。実際に残存率だけを上げたら索引が原文より大きくなった -->

残存率 6.2% を直そうとして上限を外したら、**索引が原文より大きくなった。**
**測れる指標を作った瞬間、それを最大化しに行く。**

さらに**小さい入力では割合の上限が効かない**（5,873字に対する38%は、
絶対値では 2,200字＝十分小さい）ので、**絶対値の下限も要る。**

## 設計のときに効く3つ

- **許可リストではなく拒否リストにする。**
  「通すもの」を列挙すると、**新しいものが黙って落ちる。**
  「重いものだけ弾く」なら、知らない形式でも届く
- **安全側に倒す処理ほど、誤爆を疑う。**
  429 の検出を `"rate" in err` で書いたら、`generate` に当たって正常系が止まった。
  **止める処理は、止めるべきでないものを止めていないか確かめる**
- **「失敗を検出する」より「成功の印を置く」。**
  枠切れか、クラッシュか、電源断かを機械で区別できないなら、
  **「印が無ければやり直す」の方が全部拾える**

## 追記(2026-08-27): 検査を書いたら、その検査が同じ形で壊れた

**未定義の CSS 変数を機械で落とす検査**を足した。色が消えるだけでビルドは通る、
まさにこの記事の形の不具合を潰すためのものだった。

**書いた直後、わざと壊して試したら発火しなかった。**

原因は既存の `walk()` が **`.md` しか返さない許可リスト**だったこと。
`.astro` を渡すと**0件**が返り、**空のループが常に「問題なし」を返していた。**

```js
// 対象が0件なら、検査したことにしない。空のループは常に通る
if (astro.length === 0) add('error', ..., '.astro が1つも見つからない');
```

**上の3つの教訓を全部踏んだ。** 許可リスト / 0件の成功 / 通ったから書けたと思う。

**そして「わざと壊して試す」をやっていなければ、気づかなかった。**
検査を足したときは、**必ず一度 error を出させてから戻す。**

## 未確定

- **どこまで指標を付けるべきか決まっていない。** 全部に付けると重いし、
  **指標そのものが壊れる**（今回2回起きた）。**指標を持つべき境界がまだ言語化できていない**
- **7件とも自分の作ったものだけ。** 外部のライブラリや API に同じ形があっても、
  **こちらからは指標を付けられない**

「制御を足すといくら得か」を、手元の3つの負荷で計算した。
**3つとも、比べる相手を間違えていた。**

しかも**間違いの向きが一定ではなかった。** 過大に出たものと、過小に出たものがある。

## 3件

| 何を測ったか | 使っていた比較相手 | 本当の比較相手 | ずれ |
|---|---|---|---|
| **冷蔵庫を安い時間に寄せる** | 一日中まったく平ら | **実際の使い方** | 月303円 → **月6円** |
| **LED栽培棚の点灯窓** | **最悪の窓** | 素朴に昼か夜で回す | 年7,215円 → **年1,586〜3,948円** |
| **ポタ電の充電窓** | 一日中の平均（ランダムな時刻） | 素朴に深夜に挿す | 年1,168円 → **年1,435円** |

**最初の2つは過大、3つ目は過小だった。**

## 上限と取り分は別のもの

**「最良 − 最悪」は上限であって、取り分ではない。**

栽培棚の年7,215円は、**最悪の窓で回していた人が最良の窓に移った場合**の額だ。
そんな人はいない。**誰も一番高い時間を選んでいない。**

```
最良の窓          10.03 円/kWh   毎日引き直したときの平均
素朴に昼で回す     11.60          ← ここから始まる人が多い
素朴に夜で回す     13.94
最悪の窓          17.18          ← **ここから始まる人はいない**
```

**比較相手は「制御が無かったら実際に何をしていたか」でなければならない。**
そこを最悪値に置き換えると、**上限が取り分の顔をして出てくる。**

## 逆に、過小に出ることもある

ポタ電の充電窓では逆だった。**比較相手を「一日中の平均」に置いていた。**
これは「ランダムな時刻に充電する人」で、**これも実在しない。**

実在するのは**深夜に挿しっぱなしにする人**で、その人は平均より**得をしている**
——と思いきや、この地域のこの季節では**そうではなかった。**

```
毎日いちばん安い2時間     7.25 円/kWh
素朴に深夜(02-04)        12.93          ← 平均(13.61)とほぼ同じ
```

**深夜が安いという前提が崩れているので、平均と大差が無い。**
結果、比較相手を実在する人に変えたら、**取り分は減るどころか増えた。**

## なぜ向きが一定でないのか

**比較相手が「良い側」に寄っているか「悪い側」に寄っているかで決まる。**

- 最悪値を相手にする → **実際より良い相手を無視している** → 過大
- 平均を相手にする → **実際の人が平均より上手か下手かによる** → どちらにも振れる

**「平均と比べる」は中立に見えて中立ではない。**
実在の選択が平均より上手なら過大に、下手なら過小に出る。

## 手順にしたこと

- **改善幅を出す前に、「制御が無かったら実際に何をしていたか」を1行で書く。**
  書けないなら、その数字は取り分ではない
- **上限と取り分を並べて出す。** 片方だけ出すと、読む側が取り違える
- **平均を既定の比較相手にしない。** 中立に見えるだけで、実在しない振る舞い
- **比較相手を変えたら、向きも確かめる。** 過大だと思い込んで直すと、
  今度は過小のまま気づかない

## この見方が効く先

電力に限らない。**「AI に外注していくら浮くか」も同じ形をしている。**

- 上限: **全部自分でやった場合**との差
- 取り分: **実際にやっていたやり方**との差（そもそも面倒でやっていなかったなら、
  取り分は「浮いた額」ではなく「できるようになったこと」になる）

**やっていなかったことを自動化しても、費用は減らない。**

## 未確定

- **「実際に何をしていたか」を後から正直に思い出せるか。** 冷蔵庫は実測が
  あったので言い切れたが、**栽培棚は存在しないので「素朴に昼か夜」は想像**でしかない
- **149日は4〜8月ぶん。** 昼が安いのは太陽光の効きなので、
  **冬に同じ分布になる保証は無い。** 比較相手そのものが季節で動く可能性がある
